# Maestria-Inteligencia-Artificial - Code & Projects 🚀

Repository dedicated to compiling implementations, projects, labs, and experiments developed during my Master's in Artificial Intelligence at Pontificia Universidad Javeriana in Colombia.

---

## 📌 Repository Overview

This space acts as a technical portfolio and version-controlled backup of my academic progress in Advanced AI. It includes modular code, custom scripts, predictive modeling, and pipeline architectures across different specialized subjects.

### Main Focus Areas

* **Machine Learning & Deep Learning:** Neural network architectures, hyperparameter tuning, and optimization.
* **Natural Language Processing (NLP):** Sentiment analysis, text processing, and conversational agents.
* **Data Management & Architectures:** Data engineering, ETL/ELT pipelines, and scalable database systems.
* **Intelligent Systems & Agents:** Search algorithms, decision-making systems, and autonomous logic.

---

## 🛠 Tech Stack & Tools

* **Languages:** Python, R, SQL
* **Data Science & ML:** PyTorch, TensorFlow, Scikit-Learn, Pandas, NumPy
* **NLP & LLMs:** Hugging Face, NLTK, LangChain
* **Cloud & Data:** Google Cloud Platform (GCP), BigQuery
